# Ever Habit

Просто мое экспериментальное приложение для отслеживания привычек

На данный момент я реализовал только смену темы со светлой на темную и наоборот, и запоминание этого значения в local storage.

В планах сейчас сделать диалоговое окно создания привычки, адаптив для него и сам скрипт который будет возвращать значения, очищать поля после этого и т.п.

После уже сверстаю сам блок привычки, тот же самый адаптив и буду все это соединять воедино.
